# 07 — Full Run Entry Point

This file is retained as the compatibility entry point. The controlling full-run workflow for current Paper_plan development is workflows/13_v5_manuscript_development.md.

Read together: docs/V5_PRODUCT_CONTRACT.md; docs/V5_1_RESEARCHER_FACING_DELIVERY_STANDARD.md; templates/V5_INTEGRATED_MANUSCRIPT_PLAN.md; templates/V5_INTERNAL_PRODUCT_QA_REPORT.md; docs/V5_1_NARRATIVE_PRODUCT_QA.md; and docs/V4_PRODUCT_CONTRACT.md for retained evidence/integrity invariants.

The evidence-mining and planning procedures remain in workflows/01–06 and workflows/08–12. Use them when called by V5; do not execute them as disconnected reports or treat populated bundles/validator PASS as the final product.

## Required run sequence

1. Read the V5 workflow and contract.
2. Create/identify an isolated workspace and inventory original sources.
3. Build and audit the evidence base using existing tools and V4.1–V4.3 integrity gates.
4. Reconstruct the literature frontier and bound novelty.
5. Select one defensible contribution or explain why the project should narrow/stop.
6. Design the Introduction, connected manuscript storyline, TOC/Figure/Panel plan and SI.
7. Build actionable experiment, analysis and relevant theory/computation packages.
8. Synthesize the evidence and argument into the complete researcher-facing scientific plan using the V5 template; develop the manuscript narrative, Figure/Panel design and student/collaborator task briefs in full prose.
9. Export and inspect the matching PDF. Record product review, scientific readiness, benchmark comparison and technical validation in a separate internal QA report; never append those records to the scientific plan.

The output is a supervisor-reviewable and team-assignable manuscript-development dossier, not an automatic paper or experiment runner.
