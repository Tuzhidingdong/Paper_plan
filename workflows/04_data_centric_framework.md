# 04 — Data-centric Manuscript Framework (specified; not implemented in MVP)

Organize the framework around scientific arguments and Data Slots, not preassigned Figure numbers.

Core entities:
- Claim: scientific statement to support.
- Data Slot: evidence requirement for a Claim in a manuscript section.
- Result Unit: observation extracted from the report.
- Data Unit: curated grouping/transformation of Result Units.
- Task: experiment, analysis or calculation needed to fill an unsatisfied Data Slot.

Preserve source lineage and transformations. Multiple derived Data Units from one Result Unit are not independent experiments. Claim types include Descriptive, Comparative, Associational, Causal and Mechanistic. Hypotheses cannot silently become established facts.

Arrange Data Slots into Figures/Panels only after evidence needs are clear. A missing Data Slot is a requirement, not an existing result.
