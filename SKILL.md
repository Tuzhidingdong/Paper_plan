# Experiment Report Analyzer (ERA)

ERA starts from exactly one initial data source: a PDF experimental report. The PDF may be informal, incomplete, image-heavy, or scientifically unsystematic. The current MVP preserves and inventories evidence without inventing measurements, sample identities, or scientific conclusions.

## Current scope

Implemented: PDF fingerprinting and inventory; embedded raster-image extraction; Python-generated region anchors and persistent IDs; explicit panel registration; caption-blind inspection protocol; instrument checklist records; simple sample entities and series-level sample associations; evidence and artifact-audit validation; compact prompt-context compilation.

Specified but not implemented: literature-frontier retrieval, three research routes and Gate A, Claim–Evidence Graph and Data Slot planning, Gate B revision, Introduction drafting, final manuscript framework and supplementary research-plan PDF.

Never imply that a future-stage contract has executed.

## Non-negotiable rules

1. Preserve the original PDF as read-only evidence and record SHA-256.
2. LLMs may only reference IDs generated by Python. They must not invent Region, Panel, Result, Sample, Claim, Data Slot or Task IDs.
3. First-pass visual inspection must not receive the external caption or report narrative. Inspect the crop first; compare text afterwards.
4. Distinguish FOUND, NOT_SHOWN, NOT_LEGIBLE, UNCERTAIN and NOT_APPLICABLE. A figure-level absence does not prove report-wide absence.
5. Distinguish Exact_Text, Exact_Table, Vector_Extracted, Visual_Estimate, Qualitative_Observation and Unavailable.
6. Low-resolution plots must not yield exact values. Visual estimates must carry [Visual Estimate - Raw Data Required].
7. Keep Observed, Interpreted and Hypothesized separate.
8. Audit plausible artifacts and confounders before upgrading observations into interpretations. Missing metadata creates uncertainty; it does not prove error or misconduct.
9. Unconfirmed sample mappings cannot support cross-result structure–property, causal or mechanistic claims requiring identity linkage.
10. Do not infer unreported batches, measurement runs, test conditions or raw data.
11. Python validates deterministic structure and permissions; it does not decide whether a scientific mechanism is true.
12. Keep full state on disk and pass only task-specific compact views to the model.

## Execution

Read workflows/01_result_mining.md. Load references only when needed:
- references/pdf_image_processing.md
- references/instrument_visual_checklists.md
- references/artifact_audit.md
- references/sample_identity.md
- references/scientific_claims.md

Run from the repository root:

```bash
python scripts/ingest_pdf.py /path/to/report.pdf --workspace ERA_Workspace
python scripts/extract_regions.py --workspace ERA_Workspace
python scripts/build_contact_sheet.py --workspace ERA_Workspace
python scripts/validate_evidence.py --workspace ERA_Workspace
python scripts/validate_samples.py --workspace ERA_Workspace
python scripts/compile_prompt_context.py --workspace ERA_Workspace --output ERA_Workspace/cache/prompt_context/evidence_context.md
```

Panel segmentation accepts a proposed normalized panel layout:

```bash
python scripts/segment_panels.py --workspace ERA_Workspace --spec panel_layout.json
```

Contact sheets are triage-only. They must not be used for numeric plot reading. Vector-only figures need an explicitly specified page region; automatic vector-chart detection is not claimed.

## Conditional Micro-Gate 0.5

Ask for human sample mapping only when an unresolved identity blocks a central cross-result relationship or changes a candidate interpretation. Show only decision-relevant aliases. The user may confirm, reject or defer. Deferral does not stop independent analysis.

## Capability gate

The host may not support model switching. Read the cached capability profile before high-risk visual interpretation. If the active model's required multimodal capability is unknown or below minimum, preserve extracted assets and mark the affected interpretation BLOCKED_BY_CAPABILITY. Do not silently downgrade. Do not run benchmark images on every workspace start.

## Output discipline

Report extracted content, non-extracted/vector-only regions, ambiguities, validation errors/warnings and which later stages are not implemented. Never overwrite source evidence.
