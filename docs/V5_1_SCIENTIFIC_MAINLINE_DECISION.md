# V5.1 Scientific-Mainline Decision Protocol

## Purpose
Select a defensible scientific contribution without confusing the user's intended question, available evidence, a measurement/audit issue and a convenient paper-shaped fallback. This protocol is domain-neutral: apply the reasoning method, never an example's science.

## 1. Establish project-specific intent and provenance
Extract from the current project's own brief, proposal, notes and instructions: the original scientific problem and hypothesis; intended system/scope/significance; current evidence and known limitations; and any target journal explicitly selected for this project.

Distinguish scientific input from a benchmark, prior generated plan, validation report or quality reference. A benchmark evaluates depth and usability; it is not automatically evidence and does not force its hypothesis, story, journal or structure into another project. A benchmark's journal applies only when the current run explicitly declares that benchmark's journal as the target for this same test case. Never inherit it into another project. If original intent is absent, say so rather than inventing it.

## 2. Build candidate lines without losing original intent
The candidate set is project-dependent; do not force a fixed number. Where available, include:
- the user's original intended hypothesis/contribution, assessed honestly even if current evidence is incomplete;
- materially different evidence-led candidate contributions;
- a method/measurement/validation contribution only if it has independent novelty and significance, not merely because an audit issue exists;
- a coherent conditional/hybrid option where components reinforce one argument;
- a genuine stop/defer option.

Do not promote every observation into a candidate or create cosmetic title variants.

## 3. Compare candidates using common decision dimensions
For every serious candidate, record evidence and confidence, not pseudo-precise scores:
1. Scientific significance: what understanding or capability changes if true?
2. Nearest prior art: which primary studies are closest, what did they establish, and exactly what differs?
3. Evidence support: direct/derived/indirect/uncertain evidence, including counter-evidence.
4. Causal/mechanistic adequacy: demonstrated, plausible or not assessable; alternative explanations.
5. Falsifiability: observations that strengthen, narrow, weaken or falsify the thesis.
6. Decisive evidence recovery: minimum experiments, reanalysis, data or calculations needed and how each plausible outcome changes the story.
7. Feasibility: availability of samples, records, methods, equipment, model inputs and collaborators; prerequisites/blockers.
8. Journal/audience fit: assess only against the target selected for the current project. If none is selected, keep this unresolved or conditional; never import a journal from another project or benchmark.

Use a candidate comparison table with thesis, nearest-work distinction, strongest support, strongest counter-evidence/alternative, decisive gap, feasible recovery path, readiness, risks and disposition.

## 4. Decide whether validation is a contribution or a supporting task
A measurement-validation/data-audit issue may be a supporting task for the scientific thesis, a Methods/SI quality-control component, an independently novel methods contribution, or a fallback paper only if it separately passes the significance and prior-art test.

Never pivot automatically from the original scientific hypothesis to a proxy-validation paper merely because decisive measurements are missing. First determine whether a finite, feasible evidence-recovery plan can test the original line and whether that line remains differentiated from prior art. Conversely, do not preserve an unsupported mechanism as the recommended story only because it was the original intention.

## 5. Make an explicit recommendation
Choose and explain one status:
- RECOMMENDED — best-supported and sufficiently differentiated line;
- CONDITIONAL — promising but dependent on defined decisive evidence/feasibility gates;
- HYBRID — linked components jointly establish one contribution;
- FALLBACK — independently defensible alternative if the preferred line cannot proceed;
- STOP/DEFER — no current line justifies a paper plan without material change.

State the one-sentence contribution and boundary, why it is preferable, why alternatives were deferred/rejected, what uncertainty could reverse the decision, and the human decision required. Keep approval pending until recorded.

## 6. Propagate the decision through the manuscript
The chosen line must determine the Introduction gap, Results/Discussion questions/transitions, every Figure/Panel, SI, work packages and execution critical path. A validation task may support a scientific contribution but must not silently become the central paper. Every proposed Figure and task must state which claim or decision it advances.

## 7. Required decision record
Show the original intent (or state none was supplied), candidate lines and evidence/literature basis, nearest-work differences and counter-evidence, why the selected line is stronger than an audit-only fallback where relevant, decisive missing evidence and feasible recovery, recommendation status and conditions that would change it.

No fixed candidate count, numeric score, paper structure or scientific method is required.
