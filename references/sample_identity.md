# Sample identity and mapping

Use a minimal Sample Entity with explicit aliases, optional preparation conditions, optional batch note and identity status. Embed Measurement Context in each Result Unit. Each separately labeled curve/series can have its own sample association.

Statuses: CONFIRMED, PROBABLE, AMBIGUOUS, UNMAPPED, NOT_APPLICABLE.

Do not infer a batch/run hierarchy. A preparation temperature is a condition, not automatically a unique sample identity.

Micro-Gate 0.5 is conditional: trigger only when unresolved mapping blocks a central cross-result relationship or changes a key interpretation. Human confirmation, rejection and deferral are allowed. Deferral does not block unrelated result analysis.
